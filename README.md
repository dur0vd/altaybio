# АлтайБио

Зелёная адаптивная версия сайта Алтайского биофармацевтического кластера.
Статический HTML/CSS/JavaScript без сборки и серверных зависимостей.

Адрес после включения GitHub Pages: https://dur0vd.github.io/altaybio/

## Публикация на GitHub Pages

Ветка `main` содержит исходники, парсер и папку `dist` с готовым сайтом.
GitHub Pages публикует корень ветки `gh-pages`, содержащей файлы из `dist`.
Сайт работает самостоятельно на GitHub Pages, без серверов Sites.

Однократная настройка владельцем: Settings → Pages → Source: Deploy from a branch
→ Branch: `gh-pages`, папка `/(root)` → Save. Подключение, загрузившее файлы,
не имеет права включать Pages через API (GitHub вернул HTTP 403).

После изменений и коммита в `main` обновить сайт:

```sh
git push github main
python scripts/deploy_github_pages.py github
```

В этих командах remote `github` указывает на https://github.com/dur0vd/altaybio.git.
Если репозиторий клонирован с GitHub и remote называется `origin`, используйте `origin`.

## Просмотр

```sh
python -m http.server 8000 --directory dist
```

Открыть http://localhost:8000. Маршруты используют hash, например `#/members`, `#/news`, `#/article/<id>` и `#/archive`.

## Перенос содержимого

Публичный HTTP-источник: http://altaybio.ru. Снимок от 24 октября 2026 г.:
157 страниц, 139 материалов без пагинации, 421 локальный файл, ошибок 0.
Служебные страницы, авторизация, поиск, feeds и дубли для печати исключены.
Это разовый снимок; автоматическая синхронизация не подключена.
Статистика и границы обхода: `dist/data/crawl-report.json`.
Полный массив материалов: `dist/data/source.json`.

Для повторного обхода установить `scripts/requirements.txt` и запустить:

```sh
python scripts/crawl_source.py
```

Парсер собирает все найденные публичные информационные страницы и локальные
изображения/файлы; исполняемые элементы исходного HTML удалены. Email-адреса,
скрытые Joomla, раскрыты без выполнения исходных скриптов. Даты публикаций
не выдумываются: если метаданных нет, новости упорядочены по исходному ID.

## Дизайн и изображения

Глубокий зелёный, светлая природная палитра; локальные Golos Text и Lora.
Фотографии Алтая: `dist/assets/nature/attribution.json`, Pexels License.
Лицензии локальных шрифтов: `dist/assets/fonts/sources.json`.
Новый редакционный блок о природе Алтая отделён от архивных материалов.

## Проверка

```sh
node --check dist/app.js
```

Дополнительно проверяются поиск, маршруты, пагинация, диалоги, меню,
документы, отсутствие потерянных локальных файлов и ширина мобильного экрана.
Предыдущая конфигурация Sites сохранена в `.openai/hosting.json` для истории;
она не используется GitHub Pages.
